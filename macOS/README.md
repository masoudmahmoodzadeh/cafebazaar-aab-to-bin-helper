# macOS Guide

## Requirements

- Java
- bundlesigner.jar
- Keystore
- macOS

## Script

The AppleScript used to automate the process:

(sign-aab-to-bin.applescript)

## How it works

1. Select AAB file
2. Select keystore
3. Enter credentials
4. bundlesigner runs
5. BIN file is generated

## Usage

1. Open Script Editor
2. Run the script
3. Follow the prompts
